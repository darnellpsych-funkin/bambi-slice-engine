Bambi-Slice Engine

Fork de LuaSlice para Friday Night Funkin', con V-Slice 0.8.7 y API Lua propia para mods, botplay con score y más.

API Lua

Además de la API de LuaSlice, Bambi-Slice agrega una tabla Bambi para scripts:

Bambi.version

Versión del engine.

Bambi.lang.current

Idioma activo.

Bambi.lang.tr(key)

Traduce una clave al idioma activo.

Bambi.botplay.get / set

Lee o cambia el botplay.

Bambi.ghostTap.mode

Modo de ghost tapping actual.
